## 1. Purpose

The purpose of this document is to define the proposed boundaries and applicability of the Information Security Management System (ISMS) for the selected business area of Riseup Labs.

The scope is designed for an educational simulation based on ISO/IEC 27001:2022 Clause 4.3.

## 2. Organization

Riseup Labs is a Bangladesh-headquartered global technology company providing software engineering, AI, cloud, BPO, and other technology services.

This assessment uses publicly available company profile information and fictional internal organizational data.

## 3. Proposed ISMS Scope

The proposed ISMS scope covers:

**Software Engineering & Application Development operations within the simulated Bangladesh operating environment, including software development, source code management, application testing, CI/CD activities, application deployment, and the supporting cloud infrastructure and information assets.**

The scope includes the people, processes, technologies, and information assets that support these activities.

## 4. In-Scope Activities

The following activities are included:

- Software Development Lifecycle (SDLC)
- Source Code Repository Management
- Developer Access Management
- Application Security Testing
- Code Review and Change Management
- CI/CD Pipeline Management
- Application Deployment and Release Management
- AWS Infrastructure Access Management
- Application Database Management
- Backup and Recovery
- Vulnerability Management
- Security Incident Reporting and Handling
- Employee Onboarding and Offboarding activities related to access management

## 5. In-Scope Information Assets

The following information assets are included in the proposed scope:

- Client Source Code
- Client Project Documentation
- Application Databases
- Developer Credentials
- Cloud Infrastructure Configurations
- CI/CD Pipeline Configurations
- Application Testing Reports
- Security and Access Logs
- Software Deployment Records
- Client Project Information

## 6. Technology Environment

The following technology environment is assumed for this simulation:

- Cloud Platform: AWS
- Source Code Management: GitHub
- Database: PostgreSQL
- CI/CD: GitHub Actions
- Communication: Google Workspace
- Application Environments: Development, Staging, Production

All internal technology information is fictional and has not been independently verified.

## 7. Organizational Interfaces and Dependencies

The proposed ISMS scope has dependencies on other organizational functions:

- **Human Resources:** Employee onboarding, resignation, and termination notifications relevant to access management.
- **IT Administration:** User accounts, identity management, and infrastructure support.
- **Management:** Security objectives, resource allocation, and approval.
- **Project Management:** Client requirements and project delivery coordination.

These dependencies do not automatically bring the entire departments or their unrelated activities into the ISMS scope.

## 8. Out-of-Scope Activities

The following activities are excluded from this simulated scope:

- Business Process Outsourcing (BPO) Operations
- Customer Support Operations
- HR Payroll Processing
- Finance and Accounting Operations
- Independent AI Research and Development activities
- Other unrelated business services

These exclusions apply only to this proposed portfolio scope and do not represent the actual ISMS boundaries of Riseup Labs.

## 9. Assumptions and Limitations

### Assumptions

- The organization has a Software Engineering & Application Development business unit.
- The technology environment described in this document is assumed for educational purposes.
- Internal employee roles, processes, and information assets are fictional.
- Client source code and project information are treated as confidential assets for this simulation.

### Limitations

- No internal Riseup Labs policies or procedures were accessed.
- No actual employee or client information was collected.
- No actual infrastructure configuration or security evidence was examined.
- The actual certification scope and validity of the company's publicly listed certifications have not been independently verified.
- This document does not represent an official ISMS scope or audit result.
