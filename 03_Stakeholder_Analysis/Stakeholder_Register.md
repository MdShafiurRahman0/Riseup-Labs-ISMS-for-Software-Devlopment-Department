
# Stakeholder Register

**Organization:** Riseup Labs

**Project:** ISO/IEC 27001:2022 ISMS Gap Assessment  
**Version:** 1.0  
**Status:** Draft  
**Data Classification:** Portfolio Simulation – Fictional Internal Data

## 1. Purpose

The purpose of this register is to identify internal and external interested parties relevant to the proposed ISMS scope, understand their needs and expectations, and identify the information required from them during the simulated assessment.

## 2. Internal Stakeholders

| ID | Stakeholder | Department | Responsibility | Needs / Expectations | Information or Evidence to Request |
|---|---|---|---|---|---|
| INT-001 | CTO | Management | Business and security oversight | Security governance, risk visibility, management approval | Security objectives, management review records |
| INT-002 | Development Manager | Software Engineering | Software development oversight | Secure development, controlled source code access | SDLC procedure, repository access list, code review records |
| INT-003 | DevOps Lead | DevOps | Cloud and CI/CD operations | Secure infrastructure and deployment | AWS access records, CI/CD configuration, deployment approval records |
| INT-004 | QA Lead | Quality Assurance | Application testing | Secure and reliable applications | Test plans, security testing reports, defect records |
| INT-005 | HR Manager | Human Resources | Employee lifecycle management | Controlled employee onboarding and offboarding | Joining and resignation procedures, employee status notifications |
| INT-006 | IT Administrator | IT | User account and access administration | Authorized access and timely account removal | User access list, account creation and termination records |
| INT-007 | GRC Manager | GRC | Governance, risk and compliance | Risk-based security management and compliance | Risk register, policies, compliance records |
| INT-008 | Project Manager | Project Management | Client project coordination | Protection of project information and client requirements | Client security requirements, project records |
